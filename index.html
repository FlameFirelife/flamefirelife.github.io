Foxash

a programming language i'm building around readable syntax and simple commands.

i wrote the interpreter in Rust. it has variables, functions, named loops, JSON support, and its own command-line tools.

get Foxash
foxash run
run a .foxash file
foxash check
check syntax without running it
foxash help
see the commands
